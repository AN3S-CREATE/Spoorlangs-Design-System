# Logos

The approved set: "Approved PNG set, 14 Sep 2026 (13 files, logos/approved-2026-09-14)" (Brand Book p09); "Logo SoT — Approved set, 14 Sep 2026" (p28). The 12 usable versions are listed on p10; the thirteenth, Monochrome Black, is "held back — the source file misspells the name ("SPOOOORLANS") and must be redrawn before use." (p10) and is not in this folder. "Vector masters (SVG / PDF) are not on file yet" (p09, open decision 05): every file here is a raster PNG on a solid black or white ground — no transparent cut-out exists, so crop to the lockup or match the ground. Clear space on every side is the height of the capital "S" in the wordmark; digital minimum 120 px wide for the full or horizontal lockup, print 25 mm, embroidery 70–90 mm on the chest (p11). Never stretch, rotate, recolour, add glows or shadows, or place on busy texture (p13). On Ignition Orange use no full-colour logo — the one-colour white cut-out "still to be supplied" (p12) is not here either. Inks: Ignition Orange #FF7A00 flame-S, streaks, red-zone and needle; chrome/silver arc and wordmark (no CSS token — artwork); white where noted.

Use on `asphalt-black` only, or crop to the lockup.

(p12); not used by the site. Use on `white` only.
